# GraphInstruct 项目完整文档

## 📋 项目概述

GraphInstruct 是一个专注于图理解和图推理任务的大语言模型训练与评估框架。该项目通过动态生成多样化的图结构和推理任务，旨在提升大语言模型在图算法、图分析等方面的能力。项目发表在论文 [GraphInstruct: Empowering Large Language Models with Graph Understanding and Reasoning Capability](https://arxiv.org/abs/2403.04483)。

## 🏗️ 项目结构

```
GraphInstruct/
├── GTG/                          # 图任务生成模块 (Graph Task Generation)
│   ├── generation.py             # 核心数据生成入口
│   ├── evaluation.py             # 评估模块
│   ├── utils/                    # 工具函数
│   │   └── utils.py              # 图生成算法实现
│   ├── process_node_id/          # 节点ID表示转换
│   │   ├── int_id.py             # 整数ID表示
│   │   └── letter_id.py          # 字母ID表示
│   ├── script/                   # 批处理脚本
│   │   ├── run_all_generation.sh # 批量数据生成
│   │   └── evaluation/           # 评估脚本
│   └── data/                     # 生成的数据存储
├── LLaMAFactory/                 # 模型训练框架
│   ├── data/reasoning/           # 训练数据集
│   ├── examples/                 # 训练配置示例
│   └── src/                      # 训练源代码
└── script/                       # 项目级脚本
```

## 📊 训练数据集详细分析

### 一、数据集规模

- **任务数量**：20种核心图推理任务
- **样本总量**：约20万训练样本（每个任务约10,000个）
- **数据格式**：JSON格式，兼容LLaMAFactory训练框架
- **数据总量**：约114万行（包含JSON格式化）

### 二、图推理任务分类与企业级应用场景

#### 🔄 **1. 基础图遍历算法**

**BFS（广度优先搜索）**
- **算法描述**：从起始节点按层遍历
- **企业应用场景**：
  - 🔹 **社交网络推荐**：微信/微博按关系层级推荐2度、3度好友，实现精准的「你可能认识的人」功能
  - 🔹 **网络爬虫**：搜索引擎从种子URL按层抓取网页，控制爬取深度避免陷入深层死循环
  - 🔹 **即时通讯**：查找最近的在线好友、按亲密度分层推荐群组
  - 🔹 **供应链管理**：逐级分析供应商网络（一级、二级、三级供应商），评估供应链风险传导路径
  - 🔹 **组织架构分析**：企业内部按汇报层级分析影响范围

**DFS（深度优先搜索）**
- **算法描述**：从起始节点沿路径深入探索
- **企业应用场景**：
  - 🔹 **知识图谱推理**：阿里达摩院、百度知识图谱深度挖掘实体间的多跳关系
  - 🔹 **文件系统遍历**：云盘文件检索、磁盘空间分析、病毒扫描
  - 🔹 **决策树分析**：风控系统的决策路径完整探索，追踪欺诈行为链条
  - 🔹 **迷宫/路径规划**：仓储机器人的路径探索与障碍物规避
  - 🔹 **依赖关系解析**：软件构建系统的依赖树深度分析

#### 🛣️ **2. 路径相关算法**

**shortest_path（最短路径）**
- **算法描述**：Dijkstra/A*算法，支持带权图
- **企业应用场景**：
  - 🔹 **导航系统**：高德/百度地图考虑路况、红绿灯、收费站的综合最优路径规划
  - 🔹 **物流配送**：京东/美团的智能调度系统，优化配送员路线减少配送时间30%+
  - 🔹 **网络路由**：数据包在互联网骨干网的最低延迟传输路径（OSPF协议核心）
  - 🔹 **交通调度**：滴滴打车的乘客-司机实时最短路径匹配，减少空驶率
  - 🔹 **芯片设计**：集成电路PCB布线的最短路径优化，降低信号延迟
  - 🔹 **金融套利**：跨交易所的最优交易路径，降低手续费和滑点成本

**connectivity（连通性判断）**
- **算法描述**：判断两节点是否连通
- **企业应用场景**：
  - 🔹 **网络故障检测**：阿里云/腾讯云实时监控服务器间网络可达性，秒级故障报警
  - 🔹 **社交网络分析**：LinkedIn判断两个用户间是否存在人脉连接路径
  - 🔹 **电力网络**：国家电网的输电线路连通性分析，预防大面积停电
  - 🔹 **通信基站**：5G网络覆盖连通性检测，优化基站部署
  - 🔹 **供应链韧性**：评估供应商断供后是否存在替代路径

#### 📈 **3. 重要图算法**

**PageRank（节点重要性）**
- **算法描述**：节点重要性计算（阻尼系数0.85）
- **企业应用场景**：
  - 🔹 **搜索引擎排名**：Google搜索结果排序的核心算法，改变了互联网信息分发格局
  - 🔹 **学术影响力**：知网/Google Scholar的论文/学者影响力评估（h-index扩展）
  - 🔹 **反欺诈检测**：支付宝/微信支付计算账户在资金网络中的重要性，识别洗钱中转账户
  - 🔹 **推荐系统**：抖音/快手的内容创作者权重计算，影响流量分发策略
  - 🔹 **供应链核心节点**：识别供应链中的关键供应商，优先保障其稳定性
  - 🔹 **组织影响力分析**：企业内部识别关键意见领袖(KOL)，优化信息传播策略

**MST（最小生成树）**
- **算法描述**：Kruskal/Prim算法
- **企业应用场景**：
  - 🔹 **网络布线**：电信运营商光纤网络铺设，节省成本可达20%-30%
  - 🔹 **电网建设**：输电线路规划的最小成本方案，国家电网西电东送工程应用
  - 🔹 **管道铺设**：城市燃气/水管网络建设，最小化管道总长度
  - 🔹 **集群部署**：数据中心服务器间网络连接的最优拓扑设计
  - 🔹 **物流仓储网络**：建立区域配送中心的最优连接方案

**maximum_flow（最大流）**
- **算法描述**：Ford-Fulkerson算法
- **企业应用场景**：
  - 🔹 **交通流量优化**：城市交通网络的最大通行能力计算，辅助红绿灯智能调控
  - 🔹 **供应链物流**：多仓库多配送中心网络的最大吞吐量，优化「双十一」物流调度
  - 🔹 **网络带宽分配**：CDN网络的最大数据传输能力，保障大促期间服务稳定
  - 🔹 **电力调度**：电网的最大输电容量计算，避免过载跳闸
  - 🔹 **生产排程**：制造业生产线的最大产能计算

### 二、数据生成参数配置

通过命令行参数控制生成过程：

```bash
python -m GTG.generation \
    --task shortest_path \          # 任务类型
    --file_output output.csv \      # 输出文件
    --num_samples 10000 \           # 样本数量
    --num_nodes_range "(8,15)" \    # 节点数范围
    --seed 42 \                     # 随机种子
    --hash_str "task_v1"            # 任务哈希
```

### 三、数据增强机制

#### 1. **节点ID表示多样化**
- **整数ID**：`process_node_id/int_id.py`
  - 使用数字0, 1, 2...标识节点
  - 适合数值推理任务

- **字母ID**：`process_node_id/letter_id.py`
  - 使用A, B, C...标识节点
  - 增强模型泛化能力

#### 2. **图表示形式转换**
- **边列表表示**：`[(0,1), (1,2), ...]`
- **邻接表表示**：`{0: [1,2], 1: [0,3], ...}`
- **自然语言描述**："Node 0 is connected to nodes 1 and 2..."

#### 3. **问题变体生成**
- 同一图结构可生成多个不同问题
- 支持多项选择格式（自动生成干扰项）
- 问题模板多样化

## 📌 附录：快速决策树

### 如何选择合适的图算法？

**场景：好友/内容推荐**
→ BFS（层级推荐） + common_neighbor（共同好友） + jaccard（相似度）

**场景：路线规划/导航**
→ shortest_path（最优路径） + connectivity（可达性）

**场景：风控反欺诈**
→ connected_component（团伙识别） + clustering_coefficient（紧密度） + PageRank（账户重要性） + cycle（资金回流）

**场景：网络优化**
→ MST（最小成本） + maximum_flow（最大容量） + shortest_path（最优路由）

**场景：组织/社区分析**
→ connected_component（群体划分） + PageRank（影响力） + clustering_coefficient（凝聚力）

**场景：任务调度/依赖管理**
→ topological_sort（执行顺序） + cycle（循环依赖检测）

**场景：匹配推荐**
→ bipartite（二分图匹配） + common_neighbor（协同过滤）
