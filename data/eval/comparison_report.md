## 4. 关键发现

### 4.1 BFS/DFS任务的问题
即使将`max_new_tokens`从512增加到1024，BFS和DFS任务仍然是0%准确率。
分析发现模型**没有学会使用`<<<...>>>`格式输出最终答案**，而是直接输出推理过程。

示例输出:
```
Let's run breadth-first search (BFS) step by step.
The queue of nodes to visit at the start is [14].
The queue of nodes to visit after processing node 14 is [11, 12]...
```

期望输出:
```
Let's run breadth-first search (BFS) step by step.
...推理过程...
<<<[14, 9, 6, 12, 8, 11, 2, 0, 4, 10, 1, 7, 5, 3]>>>
```
