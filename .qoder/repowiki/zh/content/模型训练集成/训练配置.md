## 核心参数详解

在LLaMAFactory中，YAML配置文件是启动监督微调（SFT）任务的核心。以下是对`llama3_lora_sft.yaml`中关键参数的详细解析：

### model_name_or_path
该参数指定预训练模型的路径或Hugging Face Hub上的模型标识符。在配置文件中，`meta-llama/Meta-Llama-3-8B-Instruct`表示使用Meta公司发布的Llama-3-8B-Instruct模型。此参数是模型加载的基础，必须准确指定。

**Section sources**
- [llama3_lora_sft.yaml](file://LLaMAFactory/examples/train_lora/llama3_lora_sft.yaml#L2)
- [model_args.py](file://LLaMAFactory/src/llamafactory/hparams/model_args.py#L33-L38)

### stage
`stage`参数定义了当前执行的训练阶段。在监督微调任务中，必须设置为`sft`（Supervised Fine-Tuning）。该参数控制训练流程的逻辑分支，确保系统执行正确的训练策略。

**Section sources**
- [llama3_lora_sft.yaml](file://LLaMAFactory/examples/train_lora/llama3_lora_sft.yaml#L6)
- [finetuning_args.py](file://LLaMAFactory/src/llamafactory/hparams/finetuning_args.py#L407-L410)

### finetuning_type
此参数决定了微调的方法。`lora`表示使用低秩适应（Low-Rank Adaptation）技术，这是一种高效的参数高效微调方法，只训练模型中的一小部分参数。`full`则表示全参数微调，训练所有模型参数。对于资源有限的场景，推荐使用`lora`。

**Section sources**
- [llama3_lora_sft.yaml](file://LLaMAFactory/examples/train_lora/llama3_lora_sft.yaml#L8)
- [finetuning_args.py](file://LLaMAFactory/src/llamafactory/hparams/finetuning_args.py#L411-L414)

### dataset
`dataset`参数指定用于训练的数据集名称。在配置文件中，`identity,alpaca_en_demo`表示同时使用`identity`和`alpaca_en_demo`两个数据集进行训练。数据集名称需在`dataset_info.json`文件中定义，该文件包含了数据集的文件路径、列映射等元信息。

**Section sources**

### template
`template`参数指定了用于构造提示（prompt）的模板。`llama3`模板是为Llama-3系列模型专门设计的对话模板，它定义了用户输入、助手响应和系统消息的格式化方式。模板系统通过`register_template`函数在`template.py`中注册，确保模型输入符合特定的对话结构。

## 硬件资源优化

为了在有限的硬件资源下实现有效训练，需要合理配置批量大小和梯度累积步数。

### per_device_train_batch_size
该参数定义了每个设备上的训练批量大小。较小的值（如配置文件中的`1`）可以减少显存占用，适用于显存有限的GPU。然而，过小的批量大小可能会影响训练的稳定性。

### gradient_accumulation_steps
当单个设备无法容纳较大的批量时，可以使用梯度累积。`gradient_accumulation_steps`设置为`8`意味着系统会累积8个批次的梯度后再进行一次参数更新，从而模拟一个更大的有效批量大小（8×1=8）。这允许在不增加显存消耗的情况下实现更大的批量训练。

## 输出参数配置

### output_dir
`output_dir`指定了训练过程中模型检查点和日志的保存路径。在配置文件中，`saves/llama3-8b/lora/sft`是相对路径，系统会在此目录下保存训练结果。

### save_steps
`save_steps`定义了每隔多少个训练步骤保存一次模型检查点。设置为`500`意味着每训练500步就保存一次模型，便于在训练中断时恢复。

### logging_steps
`logging_steps`控制日志记录的频率，设置为`10`表示每10步记录一次训练指标（如损失值）。

### plot_loss
当`plot_loss`设置为`true`时，系统会自动生成训练损失曲线图，便于直观地监控训练过程。

## 完整配置文件示例

以下是`llama3_lora_sft.yaml`的完整内容及其逐行注释：

```yaml
### model
model_name_or_path: meta-llama/Meta-Llama-3-8B-Instruct  # 预训练模型的Hugging Face Hub标识符
trust_remote_code: true  # 信任并执行来自远程的代码

### method
stage: sft  # 训练阶段：监督微调
do_train: true  # 启用训练模式
finetuning_type: lora  # 微调类型：LoRA
lora_rank: 8  # LoRA的秩（rank）
lora_target: all  # 应用LoRA的目标模块：所有线性层

### dataset
dataset: identity,alpaca_en_demo  # 训练数据集名称，用逗号分隔
template: llama3  # 使用的提示模板
cutoff_len: 2048  # 输入序列的最大长度（token数）
max_samples: 1000  # 每个数据集的最大样本数（调试用）
overwrite_cache: true  # 覆盖已缓存的预处理数据
preprocessing_num_workers: 16  # 预处理时使用的进程数
dataloader_num_workers: 4  # 数据加载器使用的进程数

### output
output_dir: saves/llama3-8b/lora/sft  # 模型和日志的输出目录
logging_steps: 10  # 每N步记录一次日志
save_steps: 500  # 每N步保存一次模型检查点
plot_loss: true  # 是否绘制并保存损失曲线
overwrite_output_dir: true  # 覆盖输出目录
save_only_model: false  # 仅保存模型权重，不保存优化器状态
report_to: none  # 不将训练日志报告给任何第三方平台（如wandb, tensorboard）

### train
per_device_train_batch_size: 1  # 每个设备的训练批量大小
gradient_accumulation_steps: 8  # 梯度累积步数
learning_rate: 1.0e-4  # 学习率
num_train_epochs: 3.0  # 训练轮数
lr_scheduler_type: cosine  # 学习率调度器类型：余弦退火
warmup_ratio: 0.1  # 预热步数占总步数的比例
bf16: true  # 使用bfloat16混合精度训练
ddp_timeout: 180000000  # 分布式训练的超时时间（毫秒）
resume_from_checkpoint: null  # 从指定检查点恢复训练（null表示不恢复）

### eval
# eval_dataset: alpaca_en_demo  # 评估数据集（注释掉表示不进行评估）
# val_size: 0.1  # 验证集比例
# per_device_eval_batch_size: 1  # 每个设备的评估批量大小
# eval_strategy: steps  # 评估策略：按步数
# eval_steps: 500  # 每N步进行一次评估
```

要启动监督微调任务，只需运行LLaMAFactory的训练脚本，并通过`--config`参数指定此YAML文件的路径。系统将自动解析配置并启动训练流程。
